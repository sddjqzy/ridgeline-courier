Ridgeline Courier is a bush-plane mail run: take off from a mountain airstrip, thread five postal rings over the ridges, and land back on the runway — watching fuel, damage and stalls the whole way. Chase view over recognisable terrain, instruments lit, altitude, speed and heading on the HUD. Keyboard and mouse, plays offline in a desktop browser, no third-party libraries, all sound synthesised with WebAudio.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
